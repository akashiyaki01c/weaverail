# Data Model

## プロジェクトファイルのデータ構造

Weaverailにおけるプロジェクトファイルの単位は、1つの直通線区等を包括した線区群であるから、このプロジェクトファイル単位を基本として様々な処理を行うことができる。

## Weaverailにおけるプリミティブ型

WeaverailのCoreにおいて、データ構造には以下の型のみを使用することとしている。

- 真偽値型 (`Boolean`)
- 整数型 (`u8`, `i8`, `i16`, `u16`, `i32`, `u32`, `i64`, `u64`, `i128`, `u128`)
- 浮動小数点数型 (`f32`, `f64`)
- 文字型 (`char`)
- 文字列型 (`String`)
- 配列型 (`Vec<T>`, TはWeaverailのプリミティブ型)
- 辞書型 (`HashMap<T>`, `IndexMapM<T>`, `FxHashMap<T>`, TはWeaverailのプリミティブ型)
- 時刻型 (`Time`)
- 識別子型 (`WeaverailId`)
- スマートポインタ型 (`Box<T>`, `Cell<T>`, TはWeaverailのプリミティブ型)
- 構造体型  (構造体の全てのフィールドがWeaverailのプリミティブ型で構成されているとき)
- 列挙体型 (列挙体の全てのフィールドがWeaverailのプリミティブ型で構成されているとき)
