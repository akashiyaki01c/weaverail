# The Weaverail Diagram Editor Books

Weaverailは、[Tauri](https://v2.tauri.app/ja/)を用いた、すべてを自由に編み上げる、直感的で強力な次世代の鉄道ダイヤグラムエディタである。
複数路線を跨ぐ列車の定義、スクリプトによるデータ変換、拡張機能プラグインに対応する。

Weaverailは、以下の考えに基き、開発している。

- 路線が枝分かれしていても、列車は走行経路のままに表現することができる。
- 全てのデータはユーザが任意に選択するものではなく、各種制約の中での最適解を導き出すものとする。
- 列車時刻はユーザが指定するものではなく、様々な制約から自動的に導出するものである。
- 拡張機能・スクリプティング機能等により、ユーザがWeaverailを拡張して使用することができる。
- Weaverail自身は、多くのことを行わず、拡張機能等を用いて実現させる。
