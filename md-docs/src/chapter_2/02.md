# Architecture Principles

## アーキテクチャの原則

Weaverailにおけるデータモデルは、全てバックエンド側に保持させ、型の安全性を強く担保させる。モデルに変更を加える際は、フロントエンド側から変更コマンドを作成し、バックエンド側に渡すことで変更を加える。データフローは以下の通りである。

1. Input User Data (or Script Input)
2. Create changing model request command by frontend
3. Update data in model by backend
4. Notice changing model to frontend by backend

モデルに対する副作用のある操作は例外なくコマンドを通じて行う必要がある。決して直接モデルを書き換えることはしてはならない。

## 状態更新の純粋性

モデルの状態更新処理は、純粋関数(Pure Function)的なアプローチに基づいて設計・実装する。
