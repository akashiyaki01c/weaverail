# Weaverail スクリプティング仕様

## 1. 目的

Weaverailのスクリプティング機能は、ユーザがTypeScriptでプロジェクトデータへアクセス・更新し、繰り返し作業や一括加工を安全に実行できることを目的とする。

第1フェーズの対象はプロジェクトデータの参照と変更とし、列車時刻再計算、ファイル入出力、拡張機能連携は対象外とする。

## 2. スコープ

### 対象

- 駅、番線、路線、駅間、列車種別、テンプレート列車、時刻表、列車の参照
- 駅、番線、路線、駅間、列車種別、テンプレート列車、時刻表、列車の新規作成・更新・削除
- 単一トランザクションでの一括変更
- スクリプト実行の成功・失敗結果と出力の表示
- スクリプト実行全体を一つのUndo/Redo操作として記録

### 対象外

- ネットワーク・ファイルシステムへの直接アクセス
- OSプロセス・シェルコマンドの実行
- DOM・ブラウザAPIへの直接アクセス
- Tauri IPCの直接呼び出し
- 任意の拡張機能モジュール読み込み
- スクリプトからの列車時刻再計算エンジン直接実行

## 3. スクリプト言語

- 記述言語: TypeScript
- 実行形式: TypeScriptをJavaScriptへ変換したうえでサンドボックスランタイムで実行
- 第1フェーズでは構文検査と型情報を含む公開宣言によるAPI補完を提供する
- 構文検査または禁止API検査に失敗した場合は実行を開始しない
- 第1フェーズではモジュール読み込み、トップレベル`await`、外部パッケージを禁止する
- スクリプト本文は同期的な関数として実行し、外部副作用はスクリプトAPIへ限定する

### 技術的固定仕様

- QuickJSのRustバインディングである`rquickjs`をランタイムとして使用する。
- フロントエンドのTypeScriptコンパイラでTypeScriptをJavaScriptへトランスパイルする。
- トランスパイル時はモジュール、トップレベル`await`、禁止されたグローバルを拒否する。
- ランタイムはモジュールローダーを登録せず、外部モジュールを解決しない。
- QuickJSの標準組込み以外に、`weaverail.project`名前空間と標準出力用関数のみを公開する。
- ホストへのブリッジはRust関数として実装し、駅・番線の参照・変更を受け付ける。
- 実行中の変更は必ず`DiagramRoot`クローンへ記録し、検証成功時のみ`CommandManager`へコミットする。
- コミットは`ScriptCommand`として一件のUndo/Redo操作にする。

## 4. スクリプト実行ライフサイクル

1. エディタからスクリプト本文を受け取る。
2. ソースサイズ、構文、型、禁止APIを検査する。
3. 実行トランザクションを開始する。
4. スクリプトをサンドボックスで実行する。
5. スクリプトAPI経由の変更をトランザクションへ記録する。
6. 全変更を検証する。
7. 成功時のみプロジェクトへコミットし、Undoスタックへ一件登録する。
8. 失敗時は全変更を破棄し、エラーを出力ペインへ返す。

### タイムアウト

- 初期既定値: 30秒
- タイムアウト時は実行をキャンセルし、トランザクションをロールバックする
- 上限値は設定可能とするが、無制限実行は許可しない

### 同時実行

- スクリプト実行中は同時実行を禁止する。
- 実行中に通常の編集を行った場合の競合を防ぐため、編集操作とスクリプト実行を排他制御する。

## 5. トランザクション仕様

スクリプト実行は以下の原子的な操作とする。

- 開始時点の`DiagramRoot`を基準状態として保持する。
- スクリプトが実行する変更は順序付きの操作ログへ記録する。
- 実行完了後に対象オブジェクトの存在、重複、外部参照、値の範囲を検証する。
- 検証成功時に変更をコミットし、バージョンを一度更新する。
- 検証失敗、例外、タイムアウト、キャンセル時に変更を破棄する。
-成功時の操作ログを一つのスクリプトコマンドとしてUndo/Redoへ登録する。

部分コミット、暗黙的コミット、実行失敗後のプロジェクト変更を許可しない。

## 6. スクリプトAPI案

第1フェーズの公開名前空間を`weaverail.project`とする。

```ts
declare namespace weaverail {
  namespace project {
    namespace stations {
      function list(): readonly Station[];
      function get(id: StationId): Station | undefined;
      function create(input: CreateStationInput): Station;
      function update(id: StationId, input: UpdateStationInput): Station;
      function remove(id: StationId): void;
    }

    namespace tracks {
      function list(stationId?: StationId): readonly Track[];
      function get(id: TrackId): Track | undefined;
      function create(input: CreateTrackInput): Track;
      function update(id: TrackId, input: UpdateTrackInput): Track;
      function remove(id: TrackId): void;
    }

    namespace lines {
      function list(): readonly Line[];
      function get(id: LineId): Line | undefined;
    }

    namespace segments {
      function list(lineId?: LineId): readonly LineSegment[];
      function get(id: LineSegmentId): LineSegment | undefined;
    }
  }
}
```

スクリプトAPIは第1フェーズで次のリソース操作を提供する。

| リソース | 一覧・取得 | 作成 | 更新 | 削除 |
|---|---|---|---|---|
| 駅 | 対応 | 対応 | 対応 | 対応 |
| 番線 | 対応 | 対応 | 対応 | 対応 |
| 路線 | 対応 | 未定 | 未定 | 未定 |
| 駅間 | 対応 | 未定 | 未定 | 未定 |
| 列車種別 | 対応 | 未定 | 未定 | 未定 |
| テンプレート列車 | 対応 | 未定 | 未定 | 未定 |
| 時刻表 | 対応 | 未定 | 未定 | 未定 |
| 列車 | 対応 | 未定 | 未定 | 未定 |

全リソースの参照APIと、既存の駅・番線CRUDを優先し、その後に残りのリソースを段階的に追加する。

### API規約

- 戻り値はスクリプト実行中のスナップショット値とする。
- オブジェクトのプロパティへ直接代入してもモデルへ反映しない。
- モデル変更は`create`、`update`、`remove`メソッド経由とする。
- 不明なID、重複ID、外部参照を伴う削除はエラーとしてスクリプトを失敗させる。
- APIは列車時刻の再計算を暗黙実行しない。

## 7. サンドボックスとセキュリティ

スクリプトランタイムはホスト環境へ到達できないサンドボックスとして実行する。

- ネットワーク、ファイル、プロセス、DOM、ブラウザストレージへ到達できない
- Tauriコマンドを直接呼び出せない
- 動的モジュール読み込み、`eval`相当機能、任意ネイティブAPIを禁止する
- 利用可能なグローバルはスクリプトAPI、標準出力、標準的な非副作用データ型に限定する
- 実行時間、メッセージサイズ、操作件数、メモリ使用量に上限を設ける

## 8. エラー仕様

エラー種別をスクリプトコンソールへ構造的に返す。

| 種別 | 表示例 |
|---|---|
| 構文エラー | スクリプトの構文を解釈できない |
| 型エラー | API引数または戻り値の型が不正 |
| APIエラー | 対象オブジェクトが存在しない、または削除できない |
| トランザクション検証エラー | モデル全体の整合性検証に失敗 |
| タイムアウト | 実行時間上限を超過 |
| ランタイムエラー | スクリプト実行中の例外 |
| キャンセル | ユーザまたはシステムにより停止 |

エラーには可能な場合スクリプト上の行・列、エラー種別、メッセージを含める。
失敗時に変更をコミットせず、ロールバック済みであることをステータスへ表示する。

## 9. スクリプトコンソールUI

スクリプトコンソールはメイン領域にタブとして表示する。

- タイトル: `スクリプト`
- エディタ領域
- 実行ボタン
- 停止ボタン
- ステータス表示
- 標準出力ペイン
- エラー詳細ペイン
- 実行中のインジケータ

実行中の再実行、通常のプロジェクト編集、スクリプトの編集を排他的に制御する。

### 対話モード

- コンソールは複数行の入力ブロックを受け付ける。
- 実行操作または`Ctrl/Cmd+Enter`で入力ブロック全体を実行する。
- 同一セッション内のQuickJSグローバル変数・関数・クラスは次のブロックへ保持する。
- 入力ブロックごとにトランザクションを開始し、成功時は一件のUndo/Redo操作としてコミットする。
- 失敗したブロックの変更はロールバックし、セッション内のJavaScript変数は直前の状態を維持できる。
- 最終文が式の場合は評価結果を出力ペインへ表示する。
- 入力履歴を保持し、`Ctrl/Cmd+上/下`で履歴を呼び出せる。
- セッションリセットでQuickJSコンテキストを破棄し、次のブロックから空の状態で開始する。

## 10. 実行結果

実行結果は次の情報を返す。

- 実行ID
- 成功・失敗・キャンセル
- 開始時刻・終了時刻
- 実行時間
- 標準出力
- エラー情報
- コミットされた変更件数
- コミット後のプロジェクトバージョン

スクリプトファイル保存・エディタ履歴・出力の永続化は第1フェーズの対象外とする。

## 11. 受入基準

以下を満たした場合、第1フェーズを完了とする。

1. TypeScriptスクリプトをエディタから実行できる。
2. 駅・番線を一覧取得できる。
3. 駅または番線をスクリプトAPI経由で作成、更新、削除できる。
4. 複数変更の途中で例外が発生しても、変更が一件もコミットされない。
5. 成功したスクリプト実行を一度だけUndoできる。
6. Undo後にRedoでスクリプト変更全体を復元できる。
7. タイムアウト時に変更をロールバックできる。
8. 禁止されたファイル・ネットワーク・プロセス・DOM操作を検出または実行不能にできる。
9. エラーをスクリプトコンソールへ行番号付きで表示できる。
10. 実行中に再実行と通常編集が競合しない。
